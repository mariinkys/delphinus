# Dictionaries

Both files are used exactly as distributed, uncompressed.

* `JMdict_e`: http://ftp.edrdg.org/pub/Nihongo/JMdict_e.gz (or the full `JMdict.gz`; only English glosses are used)
* `cedict_ts.u8`: https://www.mdbg.net/chinese/export/cedict/cedict_1_0_ts_utf-8_mdbg.txt.gz

The server memory-maps these files, so they must not be edited in place while it runs.
