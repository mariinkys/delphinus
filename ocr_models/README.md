# OCR models

Put these three files here (the Docker image downloads them automatically). They come from
[oar-ocr](https://github.com/GreatV/oar-ocr) and are Apache-2.0 licensed.

| File | Size |
|---|---|
| [`pp-ocrv5_mobile_det.onnx`](https://github.com/GreatV/oar-ocr/releases/download/v0.3.0/pp-ocrv5_mobile_det.onnx) | 4.6 MiB |
| [`pp-ocrv5_mobile_rec.onnx`](https://github.com/GreatV/oar-ocr/releases/download/v0.3.0/pp-ocrv5_mobile_rec.onnx) | 15.8 MiB |
| [`ppocrv5_dict.txt`](https://github.com/GreatV/oar-ocr/releases/download/v0.3.0/ppocrv5_dict.txt) | 72 KiB |

If any file is missing, image scanning is turned off and the rest of the app works normally.
